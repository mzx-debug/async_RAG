三个 worker 线程并行流水线执行：

```
embed_worker ──q_er──> retrieval_worker ──q_rg──> generation_worker

```

### 6.1 预更新值冻结 (L.1283–1297)

# ... 同理 prev_e1, prev_oh_e1, prev_r0, prev_r1, prev_oh_r0, prev_oh_r1

prev_K_RG = self._transfer_K_ema.get((x_r, 1), 0.0)

### 6.2 Step 1 — Embedding 拟合 (L.1299–1370)

**模型**: `emb_total = e_base × L × B + overhead_e`

```python
# 追加测量点
obs = self._emb_measurements[emb_key]  # [(L, B, emb_ms_total), ...]
obs.append((L, B, emb_ms_total))

n = len(obs)
if n == 1:
    # 单点热启动：使用 prior overhead 反解 e_base
    oh_prior = prev_oh_e0 if x_e == 0 else prev_oh_e1
    e_obs = max(0, (total_1 - oh_prior) / (L_1 * B_1))
    oh_obs = total_1 - e_obs * L_1 * B_1
    _emb_rate_ema[x_e] = EMA(e_obs)
    _emb_overhead_ema[x_e] = EMA(oh_obs)

if n >= 2:
    x_vals = [L_i * B_i for (L_i, B_i, _) in obs]
    has_variance = (max(x_vals) - min(x_vals)) > 1e-6
    if has_variance:
        # 加权指数回归：最近点权重 2^(i-n+1)，最旧点约 0.5x
        sum_w = sum_wx = sum_wx2 = sum_wy = sum_wxy = 0.0
        for i, (L_i, B_i, emb_t) in enumerate(obs):
            w = 2.0 ** (i - n + 1)
            x = L_i * B_i
            sum_w += w; sum_wx += w*x; sum_wx2 += w*x*x
            sum_wy += w*emb_t; sum_wxy += w*x*emb_t
        d = sum_w * sum_wx2 - sum_wx * sum_wx
        e_base_fit = (sum_w * sum_wxy - sum_wx * sum_wy) / d
        overhead_fit = (sum_wy - e_base_fit * sum_wx) / sum_w
        _emb_rate_ema[x_e] = EMA(e_base_fit, prev_e)
        _emb_overhead_ema[x_e] = EMA(overhead_fit, prev_oh)
    elif obs:
        # 无方差：降级为单点更新（取最新测量）
        e_obs, oh_obs = solve_single_point(obs[-1], prev_overhead)
        _emb_rate_ema[x_e] = EMA(e_obs)
        _emb_overhead_ema[x_e] = EMA(oh_obs)
```

### 6.4 Step 3 — Gen 参数拟合 (L.1422–1442)

```python
# per-token 率
gpt_obs = gen_ms_total / total_output_tokens
_gen_per_token_ema = EMA(gpt_obs)

# 平均输出长度
avg_out_obs = total_output_tokens / B
_avg_output_tokens_ema = EMA(avg_out_obs)

# gen_base（prefill 固定开销）：从总时间剥离 per-token 成本后反解
gen_per_token_cost = prev_gen_per_token * total_output_tokens  # ms
gen_base_obs = max(100, min(5000, gen_ms_total - gen_per_token_cost)) / B
# 输出 token 越多越置信：weight 从 0（短输出）渐变到 a（长输出）
token_weight = min(1.0, total_output_tokens / 200.0)
b_factor = token_weight * a
_gen_base_ema = b_factor * gen_base_obs + (1 - b_factor) * prev_gen_base
```

### 6.5 Step 4 — Transfer K 和 Queue 拟合 (L.1444–1481)

**模型**: `wall_q = max(emb+xfer_EtoR, ret+xfer_RtoG, gen) + queue_penalty`

```python
emb_q = prev_e[x_e] * L + prev_oh_e[x_e] / B
ret_q = prev_r[x_r] + prev_oh_r[x_r] / B
gen_q = prev_gen_per_token * prev_avg_out + prev_gen_base / B

xfer_ER = prev_K_ER * L if x_e != x_r else 0
xfer_RG = prev_K_RG * L if x_r != 1 else 0

emb_with_xfer = emb_q + xfer_ER
ret_with_xfer = ret_q + xfer_RG
model_max = max(emb_with_xfer, ret_with_xfer, gen_q)

wall_q = wall_time_ms / B
queue_obs = clamp(wall_q - model_max, 0, 50)
_queue_penalty_ema = EMA(queue_obs)

# 若 emb 侧是瓶颈（xE≠xR 且 emb 主导）：从 residual 反解 K[xE,xR]
if x_e != x_r and emb_with_xfer >= ret_with_xfer and emb_with_xfer >= gen_q:
    residual = wall_q - max(ret_with_xfer, gen_q)
    K_ER_obs = residual / L if L > 0 else prev_K_ER
    _transfer_K_ema[(x_e, x_r)] = EMA(K_ER_obs)

# 若 ret 侧是瓶颈（xR≠1 且 ret 主导）：从 residual 反解 K[xR,1]
if x_r != 1 and ret_with_xfer >= emb_with_xfer and ret_with_xfer >= gen_q:
    residual = wall_q - max(emb_with_xfer, gen_q)
    K_RG_obs = residual / L if L > 0 else prev_K_RG
    _transfer_K_ema[(x_r, 1)] = EMA(K_RG_obs)
```

## 7. 成本预测模型 `_estimate_action_cost` — Lines 1133–1187

用于 `next_dispatch` 中评估各 (action, batch_size) 组合的预测耗时。

### 7.1 三阶段并行模型

```
Emb (transformer encoder): emb_total = e_base × L × B + overhead_e
                           emb_per_query = e_base × L + overhead_e / B

Ret (FAISS flat):           ret_total = r_base × B + overhead_r
                           ret_per_query = r_base + overhead_r / B

Gen (vLLM continuous batch): gen_total = gen_base + gen_per_token × tokens
                              gen_per_query = gen_base / B + gen_per_token × avg_output
```

### 7.2 传输开销

```
xfer_EtoR = I(xE≠xR) × K[xE,xR] × L   (加在 Emb 侧)
xfer_RtoG = I(xR≠1)  × K[xR,1]  × L   (加在 Ret 侧)
```

### 7.3 最终公式

```python
emb_q = emb_rate[x_e] * L + emb_overhead[x_e] / B
ret_q = ret_rate[x_r] + ret_overhead[x_r] / B
gen_q = gen_per_token * avg_output + gen_base / B

emb_with_xfer = emb_q + (K[x_e,x_r] * L if x_e != x_r else 0)
ret_with_xfer = ret_q + (K[x_r,1] * L if x_r != 1 else 0)

wall_q = max(emb_with_xfer, ret_with_xfer, gen_q) + queue_penalty
return wall_q   # ms per query
```

## 附录：完整运行流程总览

```
main()
 └─ StandaloneRAGPipeline.__init__()
     ├─ GPU 检测 (torch.cuda.is_available(), total memory)
     ├─ ResourceTracker 初始化（GPU 显存预算模型）
     ├─ GreedyScheduler.__init__()（EMA 参数默认值）
     ├─ 设备映射 xE/xR → cpu/gpu
     ├─ QueryEmbeddingStage.__init__()（sentence-transformer）
     ├─ RetrievalStage.__init__()（FAISS 索引）
     ├─ GenerationStage.__init__()（vLLM LLM 引擎）
     │   └─ vLLM 加载模型到 GPU → resource_tracker.set_vllm_init_complete()
     └─ load_queries() + tokenization
 └─ pipeline.run()
     ├─ scheduler.prepare_queries()（pending queue 初始化，traces 清空）
     ├─ _warmup()（4-query E→R→G 热启动，结果丢弃）
     └─ if serial:
     │   for each pre-built microbatch:
     │       E → R → G → 累计统计 → 返回 _build_summary()
     └─ if async_v2 / async_plain:
         ├─ 启动 3 线程：embed_worker, retrieval_worker, generation_worker
         ├─ 主线程：dispatch 循环
         │   └─ scheduler.next_dispatch()
         │       ├─ 构建候选 (action, batch_size) 空间
         │       ├─ 贪心选择最低 _estimate_action_cost()
         │       ├─ _pack_batch() 打包 query
         │       └─ 返回 ScheduledMicrobatch → q_er.put()
         ├─ embed_worker：从 q_er 取 microbatch → embedding_stage()
         │   → q_rg.put(EmbeddingPayload)
         ├─ retrieval_worker：从 q_rg 取 payload → retrieval_stage()
         │   → q_out.put(RetrievalPayload)
         └─ generation_worker：从 q_out 取 payload → generation_stage()
             ├─ 累计 total_embedding/retrieval/generation_sec
             ├─ scheduler._record_batch_feedback()（EMA 拟合）
             │   ├─ Emb：线性回归 on (L×B, emb_ms)
             │   ├─ Ret：线性回归 on (B, ret_ms)
             │   ├─ Gen：per-token 率 + avg_output_tokens + gen_base
             │   └─ K + Queue：wall-time residual 分解
             └─ append BatchStats, samples
 └─ _build_summary() → JSON
```
